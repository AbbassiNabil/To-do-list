# 🚀 TaskFlow API & Dashboard

[![GitHub license](https://img.shields.io/github/license/mashape/apistatus.svg?style=flat-square)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg?style=flat-square)](http://makeapullrequest.com)

Une application complète de gestion de tâches (**To-Do List**) construite autour d'une architecture découplée. Le projet permet de gérer plusieurs listes (tableaux) de manière indépendante et d'y organiser des tâches de façon dynamique.

---

## 🗺️ Architecture des Tableaux

L'application repose sur deux concepts clés structurés via l'API :

1. **Les Listes (`todo`)** : Représentent les tableaux ou conteneurs logiques (ex: _Perso, Travail, Courses_).
2. **Les Tâches (`todolist`)** : Les éléments actionnables liés à un tableau spécifique et possédant un état propre (`todo` ou `done`).

---
